# Visão do Produto

Este documento organiza o contexto de produto vindo da mensagem do usuário.

## Experiência do usuário

O produto funciona como um hub automatizado de identidade profissional:

1. O usuário conecta o GitHub e sobe o PDF do currículo baixado do LinkedIn.
2. O sistema cruza as duas fontes.
3. O painel permite curadoria rápida do que fica visível.
4. O site final gera:
   - um link público elegante e rápido;
   - um card visual automático otimizado para o feed do LinkedIn.

## Objetivo do produto

Transformar sinais dispersos de carreira e código em um portfólio pronto, rápido e fácil de compartilhar.

## Diferenciais

- Integração entre histórico profissional e projetos reais.
- Entrada manual para projetos que não estejam no GitHub.
- Foco em geração de imagem e link com apelo de divulgação no LinkedIn.

## Pitch resumido

Hoje, o dev costuma ficar entre dois extremos: perder muito tempo montando um portfólio do zero ou depender de um perfil engessado e repositórios soltos.

A proposta é reduzir o atrito: subir o PDF, conectar o GitHub e gerar um portfólio profissional em poucos minutos.
